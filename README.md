# splittie
I am going to design a board about 18.5x18.5mm in size, it will include leds, kailh switches and diodes, and i am going to create a split keyboard with it.

I made this project because every now and then i get the urge to create a new maccropad/keyboard with this pcb, i can create it in any shape or form and it is MUCH easier to wire then a handwired keyboard.
